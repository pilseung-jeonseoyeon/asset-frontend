API 키 발급 방법

모닛은 각 기관과 계약해서 데이터를 받아오지 않습니다. 본인이 기관에서 직접 발급받은 키를 등록하면, 모닛 서버가 그 키로 대신 조회합니다. 그래서 키를 받아오는 첫 단계는 직접 하셔야 합니다.

어느 기관이든 공통으로 지켜야 할 세 가지

  • 1 비밀 키는 발급 화면에서 딱 한 번만 보입니다. 그 자리에서 복사해 두지 않으면 다시 볼 방법이 없고, 처음부터 재발급해야 합니다. 발급 버튼을 누르기 전에 붙여넣을 곳을 먼저 열어두세요.
  • 2 권한은 조회만 체크하세요. 모닛은 잔액과 체결 내역을 읽기만 합니다. 주문하기 · 출금 권한은 절대 체크하지 마세요 — 체크해도 쓰이지 않고, 키가 새어나갔을 때 피해만 커집니다.
  • 3 허용 IP에는 본인 IP가 아니라 모닛 서버 IP를 넣으세요. 기관에 접속하는 건 내 컴퓨터가 아니라 모닛 서버입니다. 내 IP를 넣으면 키가 맞아도 계속 실패합니다.
모닛 서버 IP 43.202.91.109

기관마다 부르는 이름이 다릅니다

업비트

연동 가능 가상자산
Access key모닛의 첫째 칸
Secret key모닛의 둘째 칸
  1. PC 웹브라우저로 upbit.com에 로그인합니다. 모바일 앱에서는 발급할 수 없습니다.
  2. 마이페이지 → Open API 관리로 들어갑니다.
  3. 권한에서 자산조회와 주문조회 두 개만 체크합니다. 주문하기 · 출금은 체크하지 마세요.
  4. 허용 IP 칸에 위의 모닛 서버 IP를 입력합니다. 최대 10개까지 넣을 수 있습니다.
  5. 발급된 Access key와 Secret key를 복사해 모닛에 붙여넣습니다.
  • 고객확인(KYC)과 2채널 인증을 끝낸 계정만 발급할 수 있습니다.
  • 키 유효기간은 1년이고 연장이 안 됩니다. 만료되면 업비트에서 지우고 새로 발급받은 뒤, 모닛에서도 연동을 해제하고 다시 등록해야 합니다.
  • 한 계정에 키를 최대 10개까지 만들 수 있습니다.

참고: 업비트 Open API 안내

토스증권

연동 가능 주식
client_id모닛의 첫째 칸
client_secret모닛의 둘째 칸
  1. 토스증권 계좌가 있는 상태에서 PC 웹으로 로그인합니다.
  2. 설정 → Open API에서 발급받습니다. 승인을 기다릴 필요 없이 바로 나옵니다.
  3. client_id와 client_secret을 복사합니다.
  4. 허용 IP 관리에서 위의 모닛 서버 IP를 등록합니다.
  • client_secret은 화면을 벗어나면 다시 볼 수 없습니다. 복사해 두기 전에 창을 닫지 마세요.
  • 허용 IP를 등록하지 않으면 키가 맞아도 거부(403)됩니다. 연동이 안 될 때 가장 흔한 원인입니다.

참고: 토스증권 Open API 안내

키움증권

연동 가능 주식
appkey모닛의 첫째 칸
secretkey모닛의 둘째 칸
  1. 키움증권 계좌와 키움 ID가 필요합니다.
  2. openapi.kiwoom.com에 접속해 로그인합니다.
  3. KIWOOM REST API 사용 신청을 합니다. 모의투자용과 실전용이 나뉘어 있으니 실전용으로 신청하세요.
  4. 발급된 appkey와 secretkey를 복사합니다.
  • 모의투자용 키로 신청하면 실제 계좌 데이터가 조회되지 않습니다.

KB증권

준비 중 주식
아직 모닛에서 쓸 수 없습니다. KB증권은 공개된 문서에 체결 조회 응답 형식이 정의돼 있지 않아 모닛이 아직 가져오기를 구현하지 못했습니다. 그래서 모닛 화면에서도 KB증권은 선택할 수 없게 해두었습니다. 지원이 시작되면 열립니다.
appKey모닛의 첫째 칸 (지원 시)
appSecret모닛의 둘째 칸 (지원 시)
  1. KB증권 계좌가 필요합니다.
  2. KB증권 홈페이지의 고객서비스 → Open API에서 본인인증 후 신청합니다. 2026년 8월 기준 오픈베타입니다.
  3. 발급된 appKey와 appSecret을 보관해 두세요.

키를 등록하고 나면

모닛에 키를 넣고 연동하고 가져오기를 누르면, 첫 번째로 하는 일은 계좌를 만드는 것입니다. 이때 매매 내역은 가져오지 않습니다 — “0건”이라고 나와도 잘못된 게 아닙니다.

모닛은 연동한 시점 이후에 새로 생긴 체결부터 쌓아갑니다. 그 전에 이미 사고팔았던 기록과 지금 들고 있는 종목은 자동으로 들어오지 않으니, 필요하면 계좌를 만든 뒤 직접 등록해 주세요.

다음부터는 설정 → 데이터 관리 및 백업 → 증권사 · 거래소 연동에서 가져오기 버튼을 누를 때마다 그 사이 생긴 체결이 추가됩니다. 이미 있는 기록을 고치는 일은 없습니다. 같은 화면에서 연동을 해제할 수도 있고, 해제해도 이미 만들어진 계좌와 매매 내역은 그대로 남습니다.
